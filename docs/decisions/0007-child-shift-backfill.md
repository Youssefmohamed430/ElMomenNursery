# ADR 0007 — تعبئة دوام الأطفال الحاليين

- Status: Accepted
- Date: 2026-11-24

## Decision

بعد تأكيد مالك الحضانة في 2026-11-24، تُسند قيمة «صباحي» للأطفال الموجودين عند تطبيق ترحيل `AddChildShift`. قيمة `Morning` هي القيمة الافتراضية للصنف `Shift` (0)، كما يحددها الترحيل.

## Consequences

- لا يلزم جعل `Shift` nullable ولا إضافة شاشة تأكيد لمرة واحدة.
- لا يُغيّر اختيار الدوام الافتراضي في سجل الطفل الجديد أو منطق تغييره.
